# Recall · 视觉样式规范（新拟物 / Soft UI）

> 本文件是视觉的唯一真源。所有页面只允许使用 `css/styles.css` 里定义的 CSS 变量与组件类；**页面里禁止出现硬编码的颜色、阴影、圆角**。改样式先改这里，再改 `styles.css`，最后页面自动生效。

## 1. 色彩与光影

```
--bg:#e0e5ec;        /* 全站背景基底（唯一底色） */
--bg-2:#f0f0f3;      /* 抬升表面，少量使用 */
--sh-dark:#b8bcc2;   /* 暗影：右下 (+X, +Y) */
--sh-light:#ffffff;  /* 亮影：左上 (-X, -Y) */
--mid:#d1d9e6;       /* 中间色：分割线 / 弱边框视觉 */
--accent:#6d5dfc;    /* 紫罗兰：主按钮、选中、焦点环、进度填充 */
--ok:#4ecdc4;        /* 青绿：正确 */
--bad:#ff6b6b;       /* 珊瑚：错误 */
--warn:#ffe66d;      /* 蛋黄：标记 / 重点 */
--ink:#333333;       /* 主文字 */
--ink-2:#4b5563;     /* 次要文字（正文最小字号也用它） */
--ink-3:#5b6371;     /* 弱化：仅用于不影响理解的时间、题号等辅助信息 */
```

**光影规则（硬性）**
- 光源固定左上角：负 X/Y 偏移 = 白色亮影；正 X/Y 偏移 = 暗色阴影。任何组件不得破坏该方向。
- 凸起（默认）：`box-shadow: 8px 8px 16px var(--sh-dark), -8px -8px 16px var(--sh-light)`
- 凹陷（按下 / 输入 / 凹槽）：`box-shadow: inset 4px 4px 8px var(--sh-dark), inset -4px -4px 8px var(--sh-light)`
- 移动端（max-width:767px）：阴影整体缩小一档 → 凸起 `4px 4px 8px / -4px -4px 8px`。
- 禁止：单侧阴影、CSS filter 阴影、硬边（blur=0）阴影、渐变背景、纯黑/纯白背景、粗边框（≥2px）。

**强调色的用法**：只做小面积（按钮、圆点、徽标、进度填充、勾叉图标）。禁止大面积铺底；禁止用浅色强调色写正文（对比度不够）。

**深色模式**：整套色板由 `:root[data-theme="dark"]` 覆盖变量实现（见第 8 节），组件类不复制、不改写。

## 2. 形状与动效

- 圆角：卡片 20–24px；按钮/选项/输入 12–16px；进度条胶囊形。禁止直角。
- 边框：默认不用 border；需要分隔时用 1px `--mid` 或留白。
- 过渡：`transition: box-shadow .3s ease-in-out, background-color .3s ease-in-out`（统 300ms）。
- **悬停 = 阴影缩小**（8px → 4px），模拟手指靠近遮光；禁止放大阴影。
- **按下 = 凸起变凹陷**（外阴影 → inset），**禁止任何位移/translate/缩放**。
- 输入框：默认 `inset 4px`；聚焦时**变浅**为 `inset 2px`（模拟通道打开），不要加深。
- 键盘焦点：`box-shadow: 0 0 0 3px rgba(109,93,252,.35)` 叠加在原有阴影上（用 box-shadow 实现，不用 border）。
- 尊重系统设置：`@media (prefers-reduced-motion: reduce)` 时把过渡时长压到 0.01ms。

## 3. 排版与间距

- 字体：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`；不引入外部字体。
- 字号：H1 26–30px / H2 20–22px / 正文 15–16px / 辅助 12–13px；行高 1.7。
- 数字（题号、得分、百分比、倒计时）一律 `font-variant-numeric: tabular-nums`。
- 内容区最大宽度 760px 居中；页面内边距 16px（手机）/ 24px（桌面）。
- 卡片内边距 20–24px；区块间距 20–28px。
- 间距按「阴影占位」排：带 8px 外阴影的卡片/行，视觉上会吃掉一半间距，彼此至少留 16px（`--gap-list`），否则看着就是贴在一起。
  - `--gap-tight: 8px` 标题与说明、meta 行与进度条（同一组信息，靠紧）；
  - `--gap-list: 16px` 卡片 / 记录行 / 反馈行之间；
  - `--gap-lead: 28px`（手机 20px）说明行与第一张带阴影的卡片之间；
  - `--gap-stack: 20px` 进度条与题卡之间。
  - 以上四个值只在 `css/styles.css` 的 `:root` 定义一次，页面里不写死数字。

## 4. 组件规格

**按钮**
- 次要按钮：`bg` 底 + 凸起 + `--ink` 文字；悬停阴影缩、按下凹陷。
- 主按钮：`--accent` 填充 + 白字 + 保留双影；悬停底色换成 `--accent-hover`（`#7b6cff`，强调色亮一档）并保留双影，按下凹陷。
- 任何可点元素悬停必须有可见变化（表面变 `--bg-2`/`--accent-soft`、阴影跨整档、或主色亮一档），只改文字色不算；确认框、结果页、菜单里的次要按钮同样如此。
- 尺寸：高 44–48px，左右内边距 20–24px；圆角 14px。
- 禁用：透明度 55%，阴影减弱，`cursor: not-allowed`。
- 主按钮禁用时**必须熄掉强调色**（回到 `bg` 底 + `--ink-3` 字 + 内凹阴影 + 不透明）：答题页提交后按钮变「已提交」并禁用，异常题变「本题不计分」并禁用，两者都靠这个状态表达「已经不能点了」，不能再亮着强调色。

**选项（答题页核心）**
- 默认：凸起卡片条，最小高度 52px，内边距 14px 16px，圆角 14px；左侧 28px 圆形字母徽标（凸起）。
- 悬停：阴影缩小；按下：凹陷。
- 选中：凹陷 + 徽标变为 `--accent` 底白字。
- 判定后：正确项凹陷 + 青绿勾图标；错选项凹陷 + 珊瑚叉图标；**颜色之外必须有图标/文字，不能只靠颜色**。
- 数据异常（`scorable:false`）：平面化（无阴影），选项不可选，下方一行 12px 提示「本题数据异常，不计入判分」。
- 触控区 ≥ 44px，移动端选项高度 ≥ 52px。

**卡片**：`bg` 底、圆角 22px、内边距 24px、凸起阴影；悬停（可点击时）阴影缩小。

**进度条**：凹槽轨道（inset，高 8–10px，胶囊形）+ `--accent` 填充（80% 透明度）+ 右侧等宽数字百分比。

**统计卡（结果页）**：凸起卡片，大数字 36–40px/600，下方 12px `--ink-3` 标签；三张等宽排列。

**开关**：胶囊轨道（凹陷），圆点凸起；开 = `--accent` 圆点 + 轨道保持凹陷；关 = 圆点归位。切换过渡 300ms。

**输入框**（搜索/备注等）：凹陷 4px，focus 变浅 2px，placeholder 用 `--ink-3`。

**徽标/标签**：小号胶囊（12px 字），用于「第 3 章」「已收藏」「已掌握」等；颜色用 `--mid` 底 + `--ink-2` 字，或强调色做小面积点缀。

## 5. 状态与文案（渲染层常量统一定义，不放进数据文件）

- 文案语气：平静、克制。示例：「答对了」「再看看解析」「正确答案是 B」「还有 12 题没做，确定交卷？」「本题数据异常，不计入判分」。
- 状态必须「颜色 + 图标/文字」双重表达：正确 = 青绿勾 + 「答对了」；错误 = 珊瑚叉 + 「答错了」；数据异常 = 灰字提示。
- 交卷：随时可点；未做完时先弹确认（「还有 n 题未做，确定交卷？」），**不得把交卷按钮置灰或硬拦**。
- 结果页要明确写出「参与判分 119 题（另有 1 题数据异常未计入）」这类说明，避免总数看起来像 bug。

## 6. 响应式与可访问性

- 手机优先：375px 宽无横向滚动；底部操作区（提交/上一题/下一题）固定，`padding-bottom: calc(12px + env(safe-area-inset-bottom))`，拇指可达。
- 触控目标 ≥ 44×44px。
- 文字对比度 ≥ 4.5:1（正文用 `--ink` / `--ink-2`，不要用更浅的灰写正文）。
- 全流程可用键盘完成：Tab 可聚焦、焦点环可见、Enter/Space 可操作。

## 7. 自检清单（每次改完 UI 过一遍）

- [ ] 背景是 `#e0e5ec`，没有纯白/纯黑色块、没有渐变
- [ ] 所有凸起/凹陷都是「右下暗影 + 左上亮影」双影，方向统一
- [ ] 按钮按下是凹陷，没有位移；悬停阴影变小
- [ ] 圆角统一、无可见边框（分割线用 `--mid`）
- [ ] 过渡统一 300ms ease-in-out
- [ ] 对错/选中状态有图标或文字，不只靠颜色
- [ ] 375px 宽度无横向滚动；底部操作单手可点
- [ ] 页面里没有硬编码的颜色/阴影（全部来自变量）
- [ ] 深色模式下再过一遍上面每一条（背景 `#2f3339`、双影方向不变、彩色填充上的文字用 `--on-accent`/`--on-ok`）

## 8. 深色模式与主题三态

**机制**：`<html data-theme="light|dark">` 是唯一开关，写的是**解析后的实际主题**，由 `js/core/theme.js` 写入（该文件在 `index.html` 的 `<head>` 里加载，加载即生效，避免首屏先闪一下浅色）。`css/styles.css` 里只有一组 `:root[data-theme="dark"]` 变量覆盖，**组件类一行都不改**；因此新增组件只要用变量写颜色，就自动跟随深浅两套。

**三态：跟随系统 / 亮色 / 暗色（解析规则）**
- `quiz:theme` 存的是**用户的选择**，只有三个合法值：`'system'`（默认） / `'light'` / `'dark'`。旧版本写过的 `'light'` / `'dark'` 继续认；缺失、坏数据、其它字符串一律当 `'system'`。
- 解析：`'light'→light`、`'dark'→dark`、`'system'` 看 `matchMedia('(prefers-color-scheme: dark)')`——匹配就是 dark，否则 light（拿不到 matchMedia 的旧环境按 light 算）。
- 文档上落两个属性：`data-theme` = 解析结果（CSS 只认它，也是自测量颜色的依据）；`data-theme-mode` = 用户选的三态（便于自测与排查，**不要**用它写样式）。
- `'system'` 时监听 `prefers-color-scheme` 的 `change` 实时重解析并重画；已经固定成 `'light'` / `'dark'` 时，系统偏好变化一律不影响。
- 解析结果一变，同步更新 `<html style="color-scheme">` 与 `<meta name="theme-color">`（dark `#2f3339` / light `#e0e5ec`），滚动条与手机地址栏跟着变。

**深色变量**

```
--bg:#2f3339;        /* 深灰底，不用纯黑：新拟物需要有"底面"才压得出阴影 */
--bg-2:#363a41;      /* 抬升表面 */
--sh-dark:#212429;   /* 暗影：比底色更暗（右下） */
--sh-light:#3f454e;  /* 亮影：比底色更亮（左上） */
--mid:#3b4149;       /* 分割线 / 弱底 */
--ink:#e8ebf0;       /* 主文字（对 #2f3339 ≈ 11.2:1） */
--ink-2:#c6ccd6;     /* 次要文字（对 #2f3339 ≈ 8.4:1；对 --mid ≈ 6.4:1） */
--ink-3:#9aa2ae;     /* 辅助信息（对 #2f3339 ≈ 5.6:1，只用于时间、题号等） */
--accent:#6d5dfc;    /* 强调色不变：白字 4.5:1，提亮到 #7b6cff 就掉到 3.8:1 */
--ok:#4ecdc4;        /* 正确：不变 */
--bad:#ff6b6b;       /* 错误：不变 */
--warn:#ffe66d;      /* 标记：不变 */
--on-accent:#ffffff; /* 落在强调色填充上的文字 */
--on-ok:#1f2933;     /* 落在青绿填充上的文字/图标（深色底上的深字） */
--accent-ink:#a99bff;/* 深色底上的强调色文字/图标（填充仍用 --accent） */
--overlay:rgba(18,20,23,.72); /* 弹窗遮罩 */
--sh-focus:0 0 0 3px rgba(155,144,255,.45); /* 焦点环：深底上要更亮才看得见 */
```

**光影规则（与浅色完全一致，只是两个颜色的方向关系相反）**
- 光源仍固定左上：负 X/Y = 亮影 `--sh-light`（`#3f454e`，比底色**亮**）；正 X/Y = 暗影 `--sh-dark`（`#212429`，比底色**暗**）。
- 凸起仍为 `8px 8px 16px var(--sh-dark), -8px -8px 16px var(--sh-light)`；凹陷仍为 `inset 4px 4px 8px / inset -4px -4px 8px`；移动端仍缩一档 4/8。
- 禁止把 `#ffffff` 当深色模式的亮影（会变成发光描边，破坏柔和感）；也不要用纯黑 `#000000` 当底色或暗影。

**深色下新增的三条硬性规则**
1. 落在彩色填充（强调色、青绿、珊瑚）上的文字/图标，一律用 `--on-accent` / `--on-ok`，**不要借用 `--sh-light`**（深色模式下它已经是深灰，写上去等于隐形）。
2. 强调色分两种用法：**填充**（按钮底、进度条、圆点）用 `--accent`；**深色底上的文字/图标**（如选中的范围行）用 `--accent-ink`。不要为了"显眼"把强调色提亮——`#7b6cff` 上白字只有 3.8:1。
3. 对比度按真实背景量：正文 `--ink`、次要 `--ink-2` 都要 ≥ 4.5:1；徽标这类"`--mid` 底 + `--ink-2` 字"的组合也要单独量（当前 ≈ 6.4:1）。

**入口与存储**
- 顶栏按钮 `#btnTheme`：浅色时显示「☾ 夜间」，深色时显示「☀ 日间」（显示的是"点了会切到哪"），`aria-pressed` 表示当前是否深色，任何页面都能点，只改外观、不重渲染、不打断作答。
- 选择存 `quiz:theme`（`{ theme: 'light' | 'dark' }`，经 `js/core/store.js`）；**默认浅色，不跟随系统**；坏数据、版本不符、存储不可用时一律按浅色处理。
- 切换同时更新 `<html style="color-scheme">` 与 `<meta name="theme-color">`，滚动条与手机地址栏跟着变。
